密碼核心演算法數學規格說明

像素連鎖加密 (Pixel-CBC Encryption)

正向擴散

每 3 字母映射為通道 (R_n, G_n, B_n)。第 1 組無偏移；第 n > 1 組引入前一塊密文作為連鎖偏移向量：

R'_n = (G_n + K_R + R'_{n-1}) mod 26
G'_n = (B_n + K_G + G'_{n-1}) mod 26
B'_n = (25 - R_n + K_B + B'_{n-1}) mod 26

* 濾鏡金鑰固定值：K_R = 3, K_G = 7, K_B = 12。
* 通道發生錯位輪替（G→R'、B→G'、互補R→B'），大幅加強非線性混淆（Confusion）。

逆向連鎖解密 (Pixel-CBC Decryption)

代數逆運算

對密文區塊 (R'_n, G'_n, B'_n)，利用前一塊密文偏移（n=1 時偏移為 0）進行代數還原：

R_n = (25 - B'_n + K_B + offset_B) mod 26
G_n = (R'_n - K_R - offset_R + 52) mod 26
B_n = (G'_n - K_G - offset_G + 52) mod 26

* 加上 52 確保在模 26 下所有減法運算皆為非負整數。
* 密文長度必須為 3 的倍數，結尾填充的 'X' 會被完整還原並提醒。
